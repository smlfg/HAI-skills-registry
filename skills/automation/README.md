# Automation

Skills for building, verifying and handing over business automations with real end-to-end proof.

- **[automation-delivery](./automation-delivery/SKILL.md)**: Implement or extend an automation as small, complete functions, from verified current state through technical acceptance, with one writer per artifact and a rollback path.
- **[automation-verification](./automation-verification/SKILL.md)**: Technically verify an automation against concrete criteria and current state, proving the real effect including retries, failures, recovery and stop behaviour, scaled to risk.
