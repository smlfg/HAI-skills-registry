# Productivity

Small everyday skills: time anchoring, email attachments, search, travel, voice.

- **[date](./date/SKILL.md)**: Anchor every relative time expression to the real system clock (date, time, ISO week, day of year, timezone) before answering.
- **[email-attachments-desktop-drop](./email-attachments-desktop-drop/SKILL.md)**: When an email needs attachments, put the real files into a clearly named Desktop folder for drag-and-drop instead of pushing large base64 payloads through an email MCP/connector.
- **[find-past-ai-sessions](./find-past-ai-sessions/SKILL.md)**: Hunt down an old ChatGPT, Claude, voice-recorder or agent session from fuzzy memory (a phrase, a person, a month) instead of a known URL. Connectors and full-text search first, UI scraping last.
- **[travel-operator-briefing](./travel-operator-briefing/SKILL.md)**: Act as a live travel operator for an ongoing or upcoming train/public-transport journey. Monitor connections, optimise for speed, cost and robustness, respect existing tickets, and brief only NOW / NEXT / BACKUP.
- **[voice-walkthrough](./voice-walkthrough/SKILL.md)**: Guide a user live in voice mode while they click through a UI or process themselves (dashboard, settings, form, console). They do one step, you explain it and name the next.
- **[read-aloud](./read-aloud/SKILL.md)**: Read text aloud with a local neural TTS (Piper) instead of printing it, after converting it into speakable prose.
