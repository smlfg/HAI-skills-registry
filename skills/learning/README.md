# Learning

Skills for turning course material into active practice: drills, study media, explainers.

- **[coursepack](./coursepack/SKILL.md)**: Push an entire course folder into Google NotebookLM and generate prioritised study media (audio, video, study guide) per topic and per exercise sheet, driven by the learner's real gaps and exam dates.
- **[exam-drill-site](./exam-drill-site/SKILL.md)**: Build or extend a static, offline, interactive exam-practice website from existing course material, one gated builder run per artifact. Each task is a micro-drill with progressive unlocking, two hint levels, exactly one named wrong path, and a "new numbers" generator.
